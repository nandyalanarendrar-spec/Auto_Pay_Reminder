🛡️ AutoPay Guard — Complete System Documentation

Detailed Architecture, Workflows & Implemented Features Guide | Version 1.0

1. Executive Summary

AutoPay Guard is an automated Subscription, Loan EMI, and Recurring Payment Tracker & Alert System. It safeguards users against unannounced auto-debits, unexpected credit card charges, trial expirations, and late payment penalties. Featuring multi-channel reminders (Email, Push, WhatsApp, Google Calendar) and strict GDPR data privacy compliance, it offers an end-to-end automated financial management solution.

3. Core Workflows & Implemented Features

A. Authentication & Security Flow

  • Account Registration with 6-Digit Email OTP: Users sign up with Name, Email, Phone, and Password. Registration automatically dispatches a 6-digit OTP via Brevo SMTP to verify user inbox.
  • Dual Login Options: Supports both Email + Password login and Phone Number OTP login.
  • Password Recovery ('Forgot Password' Flow): Enter Email → 6-Digit OTP sent to inbox → Enter OTP → Verified → Set New Password screen (no current password needed) → Instant password update.
  • Supabase Row-Level Security (RLS): PostgreSQL RLS policies guarantee users exclusively query and update their own records.

B. Subscription & Loan EMI Management

  • Comprehensive Tracking: Track Netflix, Spotify, AWS, Rent, Home Loans, Car EMIs, and Personal Loans.
  • Auto-Pay vs Manual Pay Modes: Distinguishes between automatic credit/debit card debits and manual bank transfers.
  • Billing Cycle & Renewal Logic: Supports Monthly, Quarterly, and Yearly cycles with precise upcoming due date calculation.
  • Financial Analytics: Real-time monthly spend outlays, upcoming auto-debits in 7 days, and trial expiration warnings.

C. Multi-Channel Reminder & Alert Engine

  • Firebase Cloud Messaging (FCM): Real-time web push notifications on desktop/mobile browsers.
  • WhatsApp Business Messaging: Automated reminder alerts delivered directly to user's WhatsApp via Meta Cloud API.
  • Google Calendar Event Sync: Automatic creation of Google Calendar event reminders on payment due dates.
  • Automated Daily Scheduler: Background engine runs daily scans triggering alerts at T-3 days, T-1 day, and on the due date.

D. Audit Logging & GDPR Compliance

  • Audit Trail: Internal AuditLoggerService records critical security events (USER_SIGNUP, USER_LOGIN, PASSWORD_CHANGE, SUBSCRIPTION_CREATE).
  • GDPR Data Portability: Download full account data, subscriptions, EMIs, and logs as JSON.
  • GDPR Right to be Forgotten: Permanently delete user profile and associated database records upon request.
